# 云备份

Loom 直接访问你自己的云存储，不需要 Loom 服务器或账号。当前支持腾讯云 COS：每个素材库只保留一份最新副本，手动更新，可拉取云端变更到当前目录，也可恢复到新目录。本地删除的文件在下次成功更新时也会从云端删除，不保留历史版本。

## 配置

云存储默认为「不使用云存储」，无需密钥，不启动云端备份任务和变更跟踪。保存此选项可停用已配置的连接，本地素材库和已有云端副本均保留。厂商配置及加密凭证仍保存在本机，重新选择该厂商即可恢复填写内容。

1. 创建一个**私有、标准存储**的 COS 桶，记下完整桶名（包含 APPID）和地域，例如 `ap-shanghai`。桶的版本控制保持关闭；已开启的桶可暂停版本控制，但已有历史版本仍需单独清理，见[版本控制配置](https://cloud.tencent.com/document/product/436/19884)。
2. 创建专用 CAM 子用户 API 密钥，只授权该桶。需要 `GetBucket`、`HeadObject`、`GetObject`、`PutObject`、`DeleteObject`、`InitiateMultipartUpload`、`UploadPart`、`CompleteMultipartUpload`、`ListMultipartUploads`、`ListParts`。见 [COS 授权指南](https://cloud.tencent.com/document/practice/436/31923)和 [Node 上传指南](https://cloud.tencent.com/document/product/436/64980)。无需修改 ACL 的权限。
3. 打开「设置 → 云备份」，选择腾讯云 COS，填写桶名、地域及密钥。数据统一存放在桶内固定的 `loom/` 目录，无需配置前缀。保存后测试连接，测试会验证列举、上传、读取及删除权限。
4. 打开素材库，点击「更新云端副本」。换电脑后配置相同的桶，刷新「云端素材库」，选择一份已完成的副本恢复，再打开恢复的素材库。

请求在 Electron 主进程中发起，无需配置桶的 CORS。凭证通过系统加密保存在 `~/.loom/`，不进入素材库。保存后的凭证保留在输入框中，默认遮罩，可查看或修改；每台电脑单独配置凭证和模型。

连接测试错误会显示失败的 COS 操作。若出现 `COS DeleteObject: AccessDenied (HTTP 403)`，检查专用子用户的 CAM 策略及桶策略是否允许在 `loom/` 下执行 `cos:DeleteObject`（包括 `loom/connection-test/` 中的临时探针）。没有需要清理的远端文件时，更新可能成功，但不代表具有删除权限。

## 存储结构

```text
loom/
  libraries/<素材库ID>/
    照片/旅行/a.jpg
    文档/笔记.md
    .loom/…                 素材库元数据及当前文件清单
  .loom/libraries/<素材库ID>.json   每个库一条当前状态
```

云端使用原文件名和相对路径，空目录也会保留。已有 `loom/v1/` 或其他自定义路径中的副本保留，新操作统一使用 `loom/`，不会自动迁移这些副本。素材库 ID 区分不同的库，根文件夹改名后仍更新同一副本。哈希只用于检查内容变化与恢复校验，不作为文件名。没有按备份时间不断增加的目录；每次覆盖当前状态。

## 更新和恢复

- 「当前素材库备份」显示上次成功备份时间、待检查变化和失败原因。记录按素材库 ID 和云存储位置独立保存在本机；切换素材库或重启仍保留。重新打开时快速对比文件属性，属性相同仍显示“需要检查”，完整预览才校验内容。
- 点击「预览变更」查看新增、修改、删除的文件与空目录及预计上传量，素材库元数据和聊天单独折叠。预览只读取云端，不上传或删除；准备时也会短暂暂停素材库和 Agent 任务，并完整读取本地文件校验内容，大素材库需要一定时间。预计上传量不包括云端清单和请求开销。
- 文件监听覆盖原始文件和备份范围内的 `.loom` 数据，排除缓存及本机授权。检查期间或之后检测到变化会将预览标为可能过期；后台元数据写入也可能触发提示。更新始终重新捕获最新状态；备份期间的新改动继续标为待检查，不会直接清空。离线状态不代表云端未被其他设备修改，预览会重新读取云端清单。
- 包含普通文件、元数据和关系图数据库、调色 LUT、聊天记录、技能、记忆和工具结果；排除预览缓存、诊断日志和本机命令授权。拒绝符号链接和特殊文件。
- 准备时停止素材库和 Agent 任务，关闭数据库，复制持久化元数据并记录文件清单，然后重新打开素材库。上传在后台进行；文件若在暂存上传前变化，更新会失败，可重试。
- 每次读取文件计算哈希，结合远端 ETag 判断是否变化。大小和修改时间匹配的候选文件先只读校验，内容及远端 ETag 一致则跳过临时副本；疑似变化的原始文件在暂存时计算哈希，已捕获的元数据直接校验上传。默认最多 3 个文件并行，原始文件暂存预算为 64 MiB，超大的单文件独占预算；临时空间约为元数据加 `max(64 MiB, 最大单文件)`。超过 8 MiB 使用分块上传，SDK 负责重试。
- 已验证文件的进度保存在 `~/.loom/`，按云存储位置和素材库 ID 隔离。失败或取消后再更新，会重新校验本地内容与远端大小、ETag，跳过一致的已完成文件；云端更新标识不匹配或记录损坏则重新上传。进度记录完成后清理，不保留任务历史。这是文件级恢复，不额外保存大文件分块进度。
- 备份进度分别显示文件上传量和已跳过文件数；校验完成量包含跳过的文件，不等于上传量。文件上传量不包含云端清单、请求开销及同一传输的重试字节。
- 文件全部上传成功后，再删除该素材库远端目录中本地已不存在的文件和目录标记；不会清理其他素材库或前缀。取消或失败后保持“未完成”状态，禁止恢复，重试会重新核验并补齐。更新期间没有上一份历史副本可回滚。
- 「拉取云端变更」比较当前素材库 ID 对应的最新云端状态。仅在成功上传、恢复或拉取后记录共同内容基准，按云存储位置、素材库 ID 和本地根目录隔离。复制或改名后的目录若没有基准，按首次拉取保守处理。只有云端改动就更新本地，只有本地改动就保留并继续待备份，两边都改动时由你选择。没有共同基准时，不确定的差异也需要选择。普通冲突可逐项或批量选择，数据库、标签、关系和聊天作为一组处理；目录删除、文件与目录替换、大小写改名按整个子树处理。
- 拉取期间暂停素材库和 Agent，应用或取消后恢复，离开云备份页会取消拉取。只下载选中的变化文件，校验内容及云端更新标识后，使用素材库旁边的独立临时目录应用；文件系统支持时快速克隆，否则复制文件，保留缓存和本机权限。没有克隆能力时需要最多一份完整素材库的临时空间。源文件变化或下载失败不会覆盖原库，重新打开失败会回滚，启动时会恢复中断的目录切换；成功后清理临时副本，不保留历史。恢复时若发现已经安装的新目录，会将其保留为旁边的 `Loom-pull-recovered-…`，避免丢失其他程序可能写入的内容。
- 恢复逐文件检查大小及 SHA-256，确认云端副本在下载期间没有更新后，在所选位置直接生成原素材库名称的文件夹，不添加外层目录。同名时追加数字，例如「照片 2」，保留已有文件和文件夹。聊天工作目录会改到新库，未完成的 Agent 请求先取消再启动调度。
- 同一素材库应在一台设备更新完成后，再在另一台拉取。旧设备上传前先拉取；「更新云端副本」仍会按本地状态覆盖云端。本版不提供云端并发写入协调或数据库逐条合并。Windows 不兼容的文件名无法在 Windows 恢复；大小写或 Unicode 重名会被拒绝。不保留文件权限和扩展属性。

建议在 COS 配置生命周期规则，延迟清理未完成的分块上传；不要自动过期或归档仍在使用的副本。此前试验上传的 `objects/` 和 `records/` 不会自动迁移或清空；确认不再需要后可在 COS 控制台手动删除。新更新只管理对应的 `libraries/<素材库ID>/` 和该库状态文件。

## 新增厂商

厂商配置及凭证类型位于 `shared/cloud-providers/`，配置必须显式指定 `provider`。扩展配置和连接类型、厂商列表及默认值，在 `main/cloud-backup/providers.ts` 注册校验和 `ObjectStore` 工厂，并在 `settings-cloud-providers.tsx` 添加表单及翻译。

控制器通过依赖注入获取工厂，备份引擎不依赖 COS。适配器负责鉴权、前缀、分页、重试和取消；提供对象大小及内容变更 ETag，原子上传完整对象，流式限制下载大小，并只删除指定对象。格式不包含厂商专属字段。

## 性能验证

在 `packages/app` 运行 `node --experimental-strip-types scripts/benchmark-cloud-backup.mjs`。脚本生成 129 MiB 素材，使用模拟请求延迟的内存存储，对比首次备份、无变化更新、单文件修改和中断重试，报告耗时、流式读写及上传量。测试不使用真实云存储，不能作为 COS 实际网络吞吐量；流式计数不包含元数据捕获及直接的 JSON 文件读写。
