# 本地 Agent Trace

Loom（所有构建，含发布版）将 trace 和指标保存到 `<素材库>/.loom/agents/traces/telemetry.sqlite`。Trace 在最后更新 30 天后过期，指标时间段在起始 30 天后过期；打开数据库时及运行期间每分钟清理。窗口按最近 40 个会话分页，每个会话逐页加载 40 条 trace；两处都支持加载更早历史。Metrics 页展示最近 200 条指标记录，打开时每秒刷新。切库重置两个视图。生产构建不记录，也不包含 trace 窗口。不上传数据。

旧 `traces.sqlite` 文件保留，不读取、不迁移。

## 采集

- 将 `DurableTrace.telemetry` 经 `LibraryRuntime` 传入 `HarnessOptions.telemetry`。Pi 提供提交、阶段、请求、轮询的原生埋点、事件、指标更新和上下文持久化传播。
- `LiveTelemetry` 实现原生适配器契约，负责 span 标识、计时、links、attributes、events、status 和指标聚合。它持久化未结束 span，支持实时显示与崩溃诊断；Chord 原生 SQLite 只保存已结束 span。
- `DurableTrace.models()` 仅向已有原生请求 span 补充脱敏输入输出，不创建请求 span，不通过 signal 或 checkpoint 推断任务归属。
- 工具 hook 补充参数；commit 内容观察器采集已完成处理的模型工具结果和嵌套程序结果（含审批拒绝、中断诊断），不采集裁剪前的 `afterTool` 结果。`DurableTrace` 仅从已提交状态更新 submission 摘要，并集中处理窗口状态规则；recorder 不解释 durable 事件。`ToolGate` 在审批等待期间记录 `loom.approval`。
- 原生输入提交各自建立根 trace。specialist 输入通过 links 关联调用它的工具，窗口展示关联；嵌套工具沿用原生 parent 关系。
- 独立 SQLite WAL 不参与 `.loom/agents/sessions/loom.sqlite` 的事务。请求发出前保存开始记录，内容更新按 100ms 合并，原生 span 结束时刷新。诊断写入失败会停用采集，Chat 继续运行。

崩溃后，未结束 span 标为 `interrupted`。原生 carrier 将恢复任务接回同一 trace，中断 attempt 仍保留。Trace 不调度、不重放工具。

## 内容与隐私

原生元数据包括 model/provider/API、stop reason、响应 ID、usage/cost、首 chunk 事件、阶段结果及有界错误。

Counter、up-down counter 和 histogram 按十秒时间段聚合次数、总和、最小值和最大值。创建 instrument 时复制配置，保留 description、unit 及传入的 histogram boundaries。桶计数非累积，包含溢出桶，可跨刷新和重启合并。每个 histogram 指标序列/时间段最多保留最近八个 exemplar，点击可打开 trace 并选中对应 span；过期引用提示不可用。活跃任务指标是增减量，不是当前任务总数。旧指标记录仍可读取，不补录历史元数据。不持久化原始测量日志。

输入输出沿用现有脱敏策略：移除已知 Chat 凭据和常见秘密模式；省略图片、签名、headers。请求保留最近 200 条消息，每条限制为 32 KiB 的 UTF-8 编码 JSON；普通 payload 限制为 8 KiB。已完成处理的工具结果不再进行第二次字节限长；Pi 的输出限制和落盘预览规则不变，脱敏与结构保护仍保留。Trace 不读取完整输出文件，历史已裁剪记录不变。请求长字符串保留 600 字符预览，已脱敏且去重的全文上限 4 MiB。每层最多保留 200 个字段或元素并附省略提示；超过 12 层的嵌套省略。限长在值和字段内部裁剪，不切断 JSON 语法。

工具定义独立保存到每个原生请求 span 的 `loom.io.tools`；消息副本仅保留新增工具名称，不重复存储 schema。Pi 在消息分页前从完整请求的工具增删记录整理可用工具。每个定义独享 4 MiB JSON 配额，允许 64 层 schema 和 100,000 个访问值；工具列表和 schema 容器不沿用普通 payload 的 200 项限制。长说明使用相同的脱敏 blob。schema 中的 `headers`、`apiKey`、`signature` 等字段名保留，真实默认值、示例和已知秘密仍脱敏。超大定义保留明确省略提示。旧记录继续读取已保存的工具增删信息，无法恢复已丢失内容。

## 查看器

会话列表按已记录的 conversation identity 分组；缺少身份的历史根 trace 单独保留。索引化摘要查询避免为构建列表加载全部 payload。不合并、不重建原生 trace/span。

事件列表按已加载的 trace 分轮次，展示系统/上下文快照、用户输入、模型回复、工具参数 → 结果、审批、重试和诊断阶段，不把请求里的历史消息重复当成新事件。输入行来自已采集的请求快照；历史输入不可用或 JSON 已截断时明确提示，不猜造。轮次/步骤编号仅针对已加载历史，不显示额外的请求编号标签。正常调度阶段（含 waiting、sleeping、下一阶段切换）不占主列表；异常、中断、重试和压缩用直白的话描述，重试后的普通请求阶段不重复列出。所有原生 span 仍保留在原始详情的“底层执行记录”中。工具结果（含文本块内的 JSON）能解析为 JSON 时使用 JSON 树；其余文本以等宽纯文本展示，保留空格和换行，不解析 Markdown。

三泳道概览默认按统一的真实耗时比例展示，保留并行及轮内等待。原生轮次之间的空闲折叠为窄分隔（通常 12px），悬浮或聚焦显示记录的实际间隔；隐藏阶段和跨轮任务等原生 span 覆盖的时间不折叠。绘图与范围聚焦使用同一投影；“时长”可切换事件等宽。短事件、0 耗时事件保留 6px 的最小可见宽度，时间线右端也不会被裁掉。执行边界上的瞬时事件按顺序独占显示位置，再接后续调用，不共用起点；调用内部的瞬时事件保留并行关系，真实并行调用不强制串行。点击与范围聚焦按实际绘制范围定位，tooltip 与存储耗时仍保持真实值。输入快照不虚构耗时；系统提示词快照显示在该轮用户输入之前，来源请求的身份和时间记录不变。点击事件块定位，拖动聚焦范围；支持搜索和手动折叠轮次/调用。实时更新保留选择和折叠状态。Metrics 和关联链接定位精确的原生 span，包括主列表中隐藏的 span。

详情提供“概述 / 预览 / 原始内容”，同一窗口内切换事件、会话或关闭再打开详情时保留所选 tab，不跨事件共享内容折叠状态。概述以本地时间显示原生调用起止时间，显示到毫秒；未结束调用标为运行中，快照明确标注来源调用时间，中断记录的恢复补填结束时间不作为真实结束时间或准确耗时。预览以 Markdown 展示正文，思考独立成区；提示词正文和工具列表默认展开，可各自独立收起，实时更新保留手动状态；收起工具列表再展开后，内部 JSON 折叠状态仍保留。不可信 HTML 转义，图片/链接不请求远程内容。原始内容是已脱敏、限长的采集副本，不是完整 HTTP 请求。系统提示词详情内分区展示工具列表（名称、说明和参数结构），优先使用独立请求快照，旧记录按已采集的工具增删信息整理；工具声明内出现明确省略标记或定义 blob 缺失时提示未完整保存，不因提示词裁剪或更早消息省略而触发。快照事件只展示自身的采集片段（系统提示词另含工具声明），不混入来源请求的全部消息和回复；来源调用元数据与可展开的全部底层记录另行标明。JSON 对象、数组和长字符串默认全部展开，只有主动点击才收起；手动状态保留到实时更新和父节点收起/展开之后。旧的不完整 JSON 回退为文本。

会话/事件列表和事件列表/详情之间的分割线可拖动，最小尺寸保证两侧可用；切换 tab 或重新打开窗口后保留布局。双击恢复默认；聚焦后支持方向键及 Home/End。查看器不再依赖第三方 trace UI 或 store。

这是尽力脱敏，不是匿名化：prompt、memory、路径和工具输出仍可能含隐私。数据库未加密。

窗口跟随应用的界面语言（英文或简体中文），在设置里切换后实时生效。文案放在 `renderer/dev-trace/trace-messages.ts`，不放进 `shared/locale.ts`：只有这个窗口用到。已采集的内容（提示词、模型输出、工具参数与结果、错误信息）按原样显示，不翻译。

## 验证

覆盖原生适配器契约（实际执行有序测量断言）、配置复制、桶与 exemplar 跨刷新/重启合并、传播与 links、实时与 SIGKILL 恢复、审批、重试、deferred poll、压缩、诊断故障隔离、脱敏、分页和 30 天清理。Electron 验收覆盖会话分组、安全 Markdown 预览、搜索/时间线聚焦、手动折叠、可调分割线、JSON 默认展开、旧文本回退、实时指标、exemplar 精确定位、重启持久化和切库后的迟到响应隔离。

独立 Electron 验收使用临时素材库和本地模型 mock：

```bash
pnpm --filter @loom/app build:e2e
cd packages/app
pnpm exec playwright test trace.spec.ts
```
