# 自动记忆

> 主对话怎样跨会话记住用户偏好和这个库的创作约定。做法仍写成 skill。待办见 [TODO](../TODO.zh-CN.md)。

---

## 1. 放在哪

当前库的笔记在 `<library>/.agents/memory/MEMORY.md`。一份文件，大约 2000 字。打开库时若没有 `.agents/memory/` 就建好。`.agents` 不收成素材。`.agents/skills/` 里的 skill 在打开库时从磁盘加载。

只记事实：用户偏好和这个库的约定。换一个库就是另一份文件。做法放在 `.agents/skills/`。

---

## 2. 系统提示

会话开始时读入这份文件，接在现有系统提示和 skill 目录后面。这一轮会话里，这份快照的字节保持不变。

`systemPrompt()` 每次生成都会调用。快照挂在这个会话上，不要每轮重读文件。会话中途写入立刻落盘。下一个会话才读到新内容。当前会话的系统提示不改。

---

## 3. 工具

主对话有一个 `auto_memory` 工具，动作是 `add`、`replace`、`remove`。`replace` 和 `remove` 用一段能唯一对上的原文定位一条笔记。工具结果给出最新全文。检索专职和生成专职不带这个工具。

它不是 `write` / `edit`，Standard 权限不会为此再要一次确认。增或改之后超过约 2000 字时，工具返回错误和当前条目。由模型自己缩短或删掉再写。不要悄悄丢掉旧条目。

---

## 4. 按当前这句话检索

第一段不做。笔记整段已经在系统提示里，没有另一份可搜的内容。

以后按这句话找到的文字，接在同一条用户消息里，和库高亮一起放进 `<system-reminder>`。不要第二条用户消息。没选中、也没检索到，就不加这段提醒。
