03 / 你可能还想知道

几个小问题。

✳
Loom 适合谁？

适合需要管理图片、视频、音频与创作参考的个人创作者，尤其是希望把参考素材、AI 生成结果和最终成片连接起来的用户。

必须配置模型才能使用吗？

浏览、预览、标签、收藏和基础文件检索不需要模型。对话操作、素材理解和向量检索需要相应模型配置；语义检索前需先完成描述和索引。

我的素材会上传到云端吗？

素材库文件保存在本地。使用云端模型时，相关文本、媒体或切片可能会发送到你配置的服务商；第三方 MCP 服务也有各自的数据处理方式。本地优先不代表所有 AI 调用都离线。

国内无法访问 GitHub，怎么下载？

当前安装包尚未发布。正式发布后，这个页面将提供独立的国内下载入口和使用说明；下载按钮会标明来源，无需先打开 GitHub。

能连接 ComfyUI 吗？

可以通过合适的第三方 MCP 服务连接。需要单独安装并配置相关服务，准备好 ComfyUI 工作流；它不是安装 Loom 后就自动可用的内置云服务。

在哪里反馈问题，或者参与贡献？

欢迎通过 GitHub Issues 反馈问题，或提交 Pull Request。独立的国内反馈入口准备中。 前往 Issues ↗
