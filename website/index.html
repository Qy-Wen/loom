    给杂乱的文件夹分类、改名、归档，一句话交给 Agent。文件移动或改名后，标签、属性和关系都会跟着走。在 Basic 权限下，每次改动文件都会先问你；命令在沙盒中运行，只能写入素材库。

    “把 Inbox 里的文件按类型归到对应文件夹，并统一命名”

  • 剪一段，压一下，发出去

安装与首次打开

该产品完全开源免费，但尚未签名公证（相关注册费用较为昂贵请见谅），下载安装后可能遇见系统提示，可按下方对应指引操作。

Windows 安装指引
  1. 下载 Windows x64 的 .exe 安装包，双击运行。
  2. 如果出现「Windows 已保护你的电脑」，点击「更多信息」→「仍要运行」，然后按安装向导完成安装。

如果没有「仍要运行」，或提示被「智能应用控制」或组织策略阻止，当前设备可能不允许安装未签名应用，请反馈具体提示。

Microsoft：了解智能应用控制 ↗
macOS 安装指引
  1. 根据芯片下载 .dmg：Apple Silicon（M 系列）选 arm64，Intel 选 x64。可在苹果菜单的「关于本机」中查看芯片类型。
  2. 打开 .dmg，将 Loom 拖入「应用程序」文件夹，再从「应用程序」打开 Loom。
  3. 如果提示「无法验证开发者」或 Apple 无法检查是否包含恶意软件，先关闭提示，再打开「系统设置 → 隐私与安全性」，在安全性区域找到 Loom 的拦截提示，点击「仍要打开」，按提示验证身份并确认打开。

如果提示应用「已损坏」或没有「仍要打开」，请重新从本页下载安装包；仍无法打开时，请反馈具体提示。

03 / 你可能还想知道

几个小问题。

✳
Loom 适合谁？

适合所有和图片、视频、音频、文档打交道的创作者：AI 绘画与视频创作者、自媒体与剪辑师、摄影师、设计师、插画师，以及需要整理参考资料的内容创作者。尤其适合想把参考素材、AI 生成结果和最终成片连接起来的人。

必须配置模型才能使用吗？

浏览、预览、标签、收藏和基础文件检索不需要模型。要开始使用 AI，先配置一个 Chat 对话模型即可。

第一个 Chat 模型这样配置：

  1. 打开「设置 → 模型」，在「对话模型」区域点击「添加服务商」，选择你使用的服务商，例如 DeepSeek。
  2. 点击该服务商下方的「API 密钥」，填入从服务商获取的 API Key 并确认，再启用要使用的模型。支持账号登录的服务商，也可以通过「登录」完成授权。
  3. 如果使用自定义服务商，选择「自定义服务商」，填写服务商提供的完整请求 URL 和模型 ID，点击「保存服务商」，再配置 API 密钥并启用模型。
  4. 回到会话，在输入框的模型菜单中选择刚配置的模型，就可以开始对话。

其他模型，例如文本嵌入（Embedding）、重排序（Rerank）、视觉理解（VLM）和音频模型，只需把对应服务商的 API Key 提供给会话，告诉 AI 想使用哪些能力，让它完成配置即可，不必逐项手动填写。

需要语义检索时，再让 AI 为素材生成描述并建立索引。

能连接 ComfyUI 吗？

可以通过合适的第三方 MCP 服务连接。需要单独安装并配置相关服务，准备好 ComfyUI 工作流；它不是安装 Loom 后就自动可用的内置云服务。

能接入内容发布功能吗？

可以，通过 MCP 接入发布工具。已实测通过 xiaohongshu-mcp 在 Loom 中完成小红书内容创作与发布。使用前需按项目说明配置服务，并登录小红书账号。 查看 xiaohongshu-mcp ↗
